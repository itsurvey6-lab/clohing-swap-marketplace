# Clothing Swap Marketplace

A MERN-based clothing exchange marketplace designed to encourage **clothing reuse and sustainable fashion** through peer-to-peer swapping.

Users can create clothing listings, browse available items, request swaps, save favorites, and communicate with other users.

## Tech Stack

* React
* Node.js
* Express.js
* MongoDB
* Mongoose
* JWT Authentication
* bcryptjs
* Multer
* Socket.io
* Axios
* Tailwind CSS
* Framer Motion

## Main Features

* User registration and login
* JWT authentication and authorization
* Create, edit, and delete clothing listings
* Clothing image uploads
* Search, filtering, sorting and pagination
* Favorites
* Swap requests and swap workflow
* Real-time messaging
* User dashboard
* Reports and admin functionality
