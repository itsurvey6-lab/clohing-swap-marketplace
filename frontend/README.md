# Frontend

The frontend is the React application for the Clothing Swap Marketplace.

It provides the user interface for browsing clothing, managing listings, requesting swaps, saving favorites, and interacting with the marketplace.

## Technologies

* React
* Vite
* React Router
* Axios
* Tailwind CSS
* Framer Motion

## Main Pages

* Home
* Login
* Register
* Listings
* Listing Details
* Create Listing
* Edit Listing
* Favorites
* Swap Requests
* Dashboard

## Main Features

* Responsive marketplace interface
* Clothing listing cards
* Search and filters
* Listing details
* Favorites
* Protected routes
* Authentication
* Image uploads
* Dashboard
* Animated UI interactions

## Running the Frontend

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The frontend runs on:

```text
http://localhost:5173
```
